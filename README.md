# tyto-template-banner

`banner`, a [Tyto](https://github.com/rafaelsilvalor/tyto) code template in its own repository:
a product banner — one text over a fixed background, in three sizes. It replaces Tyto's built-in
`banner-roxo` with one template whose configuration `roxo` keeps that name as its alias
(TYTO-435, Tyto ADR 0151 and ADR 0155).

Work in progress: the template lands on `feat/TYTO-435-banner`.
